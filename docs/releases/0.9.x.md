Each checkpoint must pass independently. Later entries are added only as their versions are completed.

## 0.9.0 — unified workspace

Task-group disclosures, bounded workspace search, command shortcuts, persistent pane/preferences, local activity, settings and shared source review are implemented. Existing editor/library actions remain available and source review does not imply permission to apply or publish.

Validation: 532 unit tests; 339 full browser tests across Chromium, Firefox and WebKit; nine follow-up navigation tests after the final search-destination fixes; production build and root/subpath static smoke. Targeted import/refresh/publishing/workspace matrix: 69 passing tests. `npm audit` reported zero advisories on 2026-09-27.

Production bundle at this stage: main JavaScript 490.19 kB / 150.02 kB gzip; highlight.js chunk 165.04 kB / 54.87 kB gzip; CSS 30.95 kB / 6.87 kB gzip; WASM 140.74 kB / 56.37 kB gzip. No dependency was added for workspace search or diffs.

## 0.9.1 — portable Studio projects

Schema-1 `.readme-studio.json` files retain canonical Markdown, supported blocks/ownership, theme/banner settings, generated SVG manifests and non-secret GitHub references. Library inclusion and preference application are explicit. Opening creates a new draft, and future/corrupt schemas offer source-only recovery. Legacy single-draft migration is sequential and source-preserving. Reload/import banner ownership IDs are repaired without rewriting source.

Validation: 540 unit tests; 90 passing storage/workspace/publishing browser regressions from the initial run; all 15 project/workspace browser tests passed after correcting the first-launch test locator. Production build and root/subpath static checks passed. Main JS reached 500.83 kB (152.73 kB gzip), triggering Vite's size advisory; splitting infrequently used UI is scheduled for the performance checkpoint.
